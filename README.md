# 讲题 · Tutor

一个给孩子的 Android 拍照讲题 App：**只讲思路，不给答案**。

拍一道作业题，它会告诉你这道题考的是什么、下一步该往哪想，然后反问你一个问题。答案永远不会出现在屏幕上——不是"藏起来了"，是压根不落地。

## 为什么做这个

市面上所有 AI 讲题工具都在比谁答得更快、更准。结果是孩子学会了拍照、复制、粘贴，然后什么都没学会。

这个项目反过来：**把"给答案"这条路堵死**，只保留引导。技术上并不难，难的是抵抗住"直接把答案说出来"的诱惑——这是大模型的默认倾向，所以需要专门设计几道闸门。

## 核心能力

| 能力 | 说明 |
|---|---|
| 拍照识题 | 拍作业本，自动识别题目并判断考查的知识点 |
| 图文同发 | 拍一整页作业，再补一句"我想问第三题" |
| 意图分流 | 自动区分「解题」「问概念」「要新题」「闲聊」，四种走不同处理 |
| 引导式解题 | 输出「考点 / 提示 / 想一想」三段，只给下一步，不给结果 |
| 概念讲解 | 问"什么是质数"这类，直接讲清楚，不套模板 |
| 举一反三 | 根据刚讲过的题，出一道同方法、不同情境的新题 |
| 双模型审核 | 生成后由另一个模型独立审核，不合格就改写或拦下 |

## 怎么保证"不给答案"

三道闸门，性质不同，不是同一句话重复三遍：

```text
① 结构约束（事前，确定性）
   模型必须输出 JSON，答案放在独立字段 answer 里，
   该字段从不进入界面，也不写入本地存储。

② 独立模型审核（事后，概率性）
   用另一个模型拿标准答案逐条比对提示和提问，
   判定「是否泄露结论」「是否步骤过多」「是否跑题」，
   不合格时优先采用改写稿，无法挽救则整条拦下。

③ 本地规则兜底（不依赖模型）
   正则扫描「答案是」「选B」「= 数字」等硬特征，
   命中则替换为兜底提示。
```

单靠 ② 不够——模型判断有漏判概率；单靠 ① 也不够——结构不能表达语义。三者叠加才稳。

## 架构

```text
┌──────────────────────────────────────────┐
│  Compose UI                              │
│  拍照 / 相册 / 输入框 / 聊天气泡          │
└────────────────┬─────────────────────────┘
                 │
                 ▼
┌──────────────────────────────────────────┐
│  TutorApi                                │
│  ├─ explain()   生成：多模态或纯文本      │
│  ├─ review()    审核：比对答案            │
│  ├─ generateSimilar()  举一反三出题       │
│  └─ reviewSimilar()    审核新题           │
│                                          │
│  模型降级链 + 429 重试                    │
└────────────────┬─────────────────────────┘
                 │ HTTPS
                 ▼
        智谱开放平台（免费模型）
        glm-4.6v-flash / glm-4.7-flash
```

## 技术栈

- **Kotlin + Jetpack Compose**，minSdk 26
- **OkHttp** 直连，不引第三方 SDK
- **智谱开放平台**免费模型（`glm-4.6v-flash` 视觉、`glm-4.7-flash` 文本）
- 无后端、无账号体系，全部本地运行

## 快速开始

### 1. 申请免费 API Key

去 [open.bigmodel.cn](https://open.bigmodel.cn) 注册，创建 API Key。`glm-4.6v-flash` 和 `glm-4.7-flash` 都是免费模型，个人使用额度足够。

### 2. 配置

复制 `local.properties.example` 为 `local.properties`，填入：

```properties
sdk.dir=C\:\\Users\\你的用户名\\AppData\\Local\\Android\\Sdk
zhipu.key=你的Key
```

> `local.properties` 已被 `.gitignore` 排除，不会提交到仓库。

### 3. 构建

```bash
./gradlew :app:assembleDebug
```

或直接用本地 Gradle：

```bash
gradle -p . :app:assembleDebug
```

产物在 `app/build/outputs/apk/debug/app-debug.apk`。

### 4. 安装

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

首次启动若 Key 为空，会弹出设置框。也可以在设置里覆盖内置 Key。

## 关于 API Key 的两条说明

1. **Key 会被编译进 APK**（`BuildConfig.ZHIPU_KEY`）。字符串最终存在于 dex 里，拆包可提取，任何客户端内置 Key 都是这样。
2. 因此**不要把编译好的 APK 分发给别人**——额度是共享的，别人用就是消耗你的。

若要多用户使用，正确做法是加一层服务端代理，Key 只存在服务端。

## 已知限制

- **只支持 Android**，未做 iOS
- **免费模型高峰期会 429**，已做模型降级与重试，但仍可能失败
- **答案完全不落地**，家长无法核对孩子做得对不对
- 单用户设计，无账号、无云端同步
- 未做 R8 压缩，APK 约 9MB
